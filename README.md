# ToDo-list-Flask
A class project about using advanced processes to develop a digital  technologies outcome in this case a ToDo-list


# ToDo-list functionality and client demands
purpuse:
Give the user an organising tool that helps manage their daily life and work tasks, effectively making it easier to achieve their goals or objectives.

features:  
- hava a side bar with that allows control over the tasks:
    - an add task butons that allows to create tasks
    - a couple of buttons to open diferent pages:
        - on top of the bar account option (add at the end)
        - button to open tasks for; today, upcomming, goals/ongoing and completed
        - when click button should stay highlighted to indicate that it is open

- be able to creat tasks that can be: certain day, an ongoing task, a goal
    - goal must have an importance rating (from 1 to 10)
- be able when adding/creating tasks to:
    - set a time/date (with all day obtion should be selected by default)
    - make them repeatable(e.g; every day/week)
    - set a deadline (no start but completed before XX:XX:XXX)
    - set sub tasks ( make a list of groceries for exemple)

 
- have a home page that gives simple control over the task:
    - displays task; today, upcoming, ongoing and goals
    - give a simple way to complete or delete a task (add comfirmation to delete a task)
